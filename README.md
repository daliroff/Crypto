# Crypto Trading: Zero to Hero

> **From complete beginner to confident, disciplined crypto trader — one module at a time.**

This course is a structured, no-hype guide to understanding and trading cryptocurrency. It covers everything from how blockchain works to deploying automated trading bots, with a focus on building real skills, sound risk management, and independent thinking. Every concept is grounded in practice, not promises.

---

## Prerequisites

- Basic computer literacy (browsing the web, installing software)
- A willingness to learn and think critically
- No prior finance or programming experience required
- Python lessons assume zero background — all concepts are introduced from scratch

---

## What You'll Learn

- How blockchain technology and cryptocurrency networks actually work under the hood
- How to securely set up and use exchanges, wallets, and essential trading tools
- How to read price charts and apply technical analysis with confidence
- How to evaluate crypto projects using on-chain data and fundamental research
- How to design, test, and execute trading strategies with defined rules
- How to protect your capital through disciplined risk and position management
- How DeFi protocols work — including DEXs, lending, yield farming, and staking
- How to automate trading logic using Python and connect to exchange APIs

## How to Use This Course

1. **Work sequentially.** Each module builds on the last. Resist the urge to skip ahead to trading strategies before finishing the foundations.
2. **Take notes.** The GLOSSARY is a starting point — your own definitions stick better.
3. **Practice with paper trading.** Before risking real capital, simulate trades on any exchange that offers a testnet or sandbox.
4. **Run the code.** The Python scripts in `/code` are meant to be executed, modified, and broken. Learning by doing is essential for the automation modules.
5. **Come back.** Markets change. Re-reading a module after three months of live observation will feel completely different.
6. **Use the glossary.** When you encounter an unfamiliar term anywhere in the course, check [GLOSSARY.md](GLOSSARY.md) first.
